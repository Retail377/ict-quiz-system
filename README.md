# ICT网络赛道刷题系统

一个功能完整的ICT网络赛道刷题系统，支持Web端和桌面端，涵盖无线、安全、网络、VLAN、数通五大考点。

## 📋 功能特性

### 核心功能
- ✅ **随机刷题**：从题库随机抽取题目练习
- ✅ **分类刷题**：按考点分类专项练习
- ✅ **错题集**：自动收录答错题目，支持重做
- ✅ **收藏夹**：手动收藏重点题目
- ✅ **每日打卡**：记录每日刷题，连续打卡统计
- ✅ **学习统计**：正确率、考点分布、趋势图
- ✅ **月度收获**：日历热力图展示每月学习情况
- ✅ **模拟考试**：限时模拟考试

### 扩展功能
- ✅ **Web界面**：基于Flask，浏览器访问
- ✅ **桌面应用**：基于Tkinter，本地运行
- ✅ **PDF导入**：用pdfplumber自动解析PDF题库
- ✅ **图表统计**：ECharts（Web）+ matplotlib（桌面/导出）
- ✅ **命令行工具**：PDF批量导入、图表导出
